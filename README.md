🍔 Divina Hamburgueria - Landing Page Bem-vindo à Divina Hamburgueria! Este é um site moderno e responsivo desenvolvido para apresentar nossa lanchonete, destacar nossos serviços e facilitar os pedidos dos clientes.

📝 Sobre o projeto Este projeto é uma landing page interativa que traz informações sobre a hamburgueria, como: ✔️ Nossa história e missão ✔️ Cardápio completo ✔️ Horários de atendimento ✔️ Opção de pedido via WhatsApp

🚀 Tecnologias utilizadas HTML5
CSS3 
JavaScript (com jQuery) 
Font Awesome (ícones)


Owl Carousel (carrossel de imagens)
